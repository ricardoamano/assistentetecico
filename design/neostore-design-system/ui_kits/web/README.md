# Marketing site — UI kit

Recreated landing-page template for **neostore.com.br**. Sections:
- Header (sticky, light)
- Hero (dark institutional)
- Services (cards grid)
- Stats / proof
- Process (numbered)
- CTA band
- Footer

Built with React 18 + inline JSX. All visual tokens come from `colors_and_type.css`. Photography is intentionally placeholder — replace with real backstage / equipment photos before publishing.
